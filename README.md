# HWID Lab

Небольшой учебный проект для просмотра системной информации Windows и изучения вопросов приватности.

> Проект работает только с собственным устройством или с разрешения его владельца.

## Возможности

- Показывает выбранные системные сведения в удобном виде.
- Объясняет, откуда берутся отображаемые значения.
- Использует вымышленные данные в примерах документации.

## Принципы работы

Проект предназначен обхода банов во всех играх. Он  изменяет и подменяет аппаратные идентификаторы,  вмешивается в античит и  предназначен для обхода блокировок или контроля доступа.

## Приватность

Перед использованием проверьте, какие данные собирает программа, где она их обрабатывает и отправляет ли куда-либо. Не публикуйте реальные идентификаторы устройства в issue, логах и скриншотах.
